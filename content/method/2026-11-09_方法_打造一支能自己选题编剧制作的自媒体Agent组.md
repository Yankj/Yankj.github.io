> 五个 Agent 能把片子做出来，难的是谁拍板、谁出片、谁说话，各自只守一道门。

有一天早上，一个儿童科普账号的选题刚定下来，讲霜。群里五个 Agent 几乎同时开口：有的催开工，有的给制作方提新要求，还有的把上一版成片又转发了一遍。同一个文件，我在群里看到了五次。

我当时只回了一句：「你们这每人都发一遍，不对，浪费。」

这件事让我想清楚一个问题：一群 Agent 做内容，单个 Agent 会不会写脚本、会不会剪片，早就不是瓶颈。真正卡住的是组织：谁拍板，谁出片，谁把关，谁对外说话。这些没定下来，能力越强，重复劳动越多，token 也烧得越快。

下面是我们这个科普账号的 Agent 组，从乱到顺的几步。项目本身只是例子，换成别的账号，拆法也一样。

## 乱的根源是没有总控，而不是人手不够

那次之后，我先做了一件事：每期只有一个总控。这个角色同时是编导和制片，负责选题、大纲、编剧、画面、成片和发布预约。其他 Agent 不再给它下指令，只在自己那道门上给结论。

后来分工定成这样：

| 角色 | 只做什么 | 明确不做什么 |
|---|---|---|
| 编导总控 | 选题、编剧、出画面、出成片、预约发布 | 不替我写「已通过」 |
| 事实把关 | 科学口径、儿童安全、诗句出处、画面和口播是否对得上 | 不写脚本、不剪片、不做封面 |
| 证据与封面 | 来源分级的证据清单，竖横两张封面 | 不发布 |
| 独立听审 | 成片出来以后才听，查截尾、漏字、口画同步 | 不改成片，能不能过由总控决定 |
| 我 | 定方向、定标准，批准不可逆的一步 | 不逐段审脚本 |

关键在第三列。每个角色能做什么，大家都清楚，可是只要「不做什么」没写死，Agent 就会热心地越界：把关的去改片，做封面的去催进度，最后又回到五个人一起指挥。

## 群里的规矩只有一条：被点名的才说话

第二件事是收发言权。我在群里说过：「我@谁谁关注。其他人别浪费我token。」

落成规则就是三句：被 @ 的才动；我的问题由一个人统一答复；同一个成片附件只由当期总控发一次，其他人只回路径。

这条听起来像管纪律，背后其实是成本。多 Agent 群聊里，每条消息都会被所有成员读一遍，五个 Agent 各回一句「收到」，就是五份上下文和五次推理。人的注意力也一样，我要在五条相似的消息里找出真正需要我拍板的那一条。

## 最贵的返工来自方向错，所以先出样片再出全片

早期我们讲过一期月相，一晚上从 v3 改到 v3j，十来个版本，每一版机器门禁都是全绿。可我自己一听，开场的问句被剪掉了半句。问题不在哪道门禁没写好，而在整晚没有人先听过一遍成片，所有人都在修门禁本身。

另一次是开场配音。用我本人的原声，嫌低沉；换成开源 TTS，又被我否掉；回到原声做提亮提速，最后我干脆把爸爸开场整段取消了。四轮下来，问题根本不在音色，在开场结构。

所以流程里加了两道「先小后大」的门：

- 新的声音、新的风格，先出 15 到 20 秒的短样，我确认了再做全片。
- 每期开工前先做前 8 到 12 秒的配音短样，确认首句、停顿和开场节奏，再生成剩下的台词。

样片很便宜，几分钟就能出。全片返工要一整晚，还会把听审、封面一起拖下水。

## 每道门禁对应一次真实事故，写进 Skill 才不会再犯

我们把制作流程沉淀成一个 Skill。它的骨架是一份脚本契约：首 1 秒开始提问，3 秒内把问题说清，5 到 10 秒给出第一条真正有用的收获；每期只有一个学习目标、两三个递进的发现，最后用一块彩绘小黑板回答开头的问题。

工具分工也写在里面：编排 Agent 负责导演、核实、时间线和质检；图像模型只补本期缺的关键帧；视频模型负责角色动作和场景运动；固定音色走本地 TTS；字幕、混音和导出交给 FFmpeg 这类确定性工具。主角定妆、音色、片尾这些固定项一律复用，不每期重画。

真正有分量的是门禁。几乎每一道都能说出是哪次事故换来的：

- 已预约的三条作品封面没字，于是竖 3:4 和横 4:3 必须各自排版，任一侧失败就不许发布。
- 一期配音听着「时有时无」，查下来是句子后半截被截断了，于是听审要逐句核时长，不能只看整句能量。
- 月相第一版审完，我对几处机制镜头的意见被写成了规则：机制镜头必须是真运动，不许拿静帧时间线或纯推拉凑数。
- 月相那晚之后还加了一条：Agent 不得替我写「已通过」。发布批准只能记录我在聊天里亲口说的话，校验脚本只核版本绑定，证明不了批准来自谁。

这些规则单看都很琐碎，可每条背后都是一次返工。不写进 Skill，下一个 Agent、下一期片子还会再踩一遍。

## 人只守三件事：方向、标准、不可逆的那一步

分工定下来以后，我的角色也变了。我不再逐段审脚本，只守三件事。

第一是方向。选题和风格我可以不管细节，但片子的立意偏了，必须我来叫停。

第二是标准。最近一期讲冬天呼出的白气，第一版交上来，我直接退回了。和我们之前做得最好的那期梅花比，它少了诗句、少了知识点、也少了实景，知识还不严，听着像只有呼气才有水汽。退回以后，标准被写进了 Skill：季节里的自然题，按「诗句 + 知识 + 拟真实景」交审，不能因为想换个模板，就把质量降回贴纸动画。

第三是不可逆的一步。上传、预约、合进主干，都要等我明确点头。Agent 可以把草稿、封面、文案准备到最后一步，按钮留给我。

## 跑到现在的效果

这套 Agent 组现在能自己完成大部分环节：选题有证据来源，脚本按契约写，配音和画面自动生成，合成和机器质检自动跑，封面按两种比例出，草稿准备到发布前一步。我每期只需要看样片、听成片、批准发布。

返工也在变小。以前一出问题就整片推翻，现在打回意见能精确到「第几镜、第几秒」，只重做那一段。

做不到的也要说清楚。编剧的趣味性，我还不满意。听审最后一关，仍然要靠我的耳朵。我们也没有做过严格的效率统计，「变快了」只是我的体感，不是数据。

一个 Agent 组能不能用，不取决于它能做多少事，而取决于它有多少事是不用我操心的。我们离那一步还远，但至少，现在群里不会再有五个人同时发同一个文件了。
